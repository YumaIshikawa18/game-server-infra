## Q1. [プロダクト] オペレーターの権限レベルはどれにしますか？

Minecraft の権限レベルは、3 で `/kick`、`/ban`、`/op` まで、4 で `/stop` なども使えるようになります。ご希望の `/gamemode` と `/kick` はレベル 3 で足ります。ゲーム内の `/stop` は、バックアップや EC2 の停止を行う通常の停止処理（`stop.sh`）を通らずにサーバーを止める点が判断材料です。なお、イメージは既存の項目のレベルを保持するため、後からレベルを変えても既存の項目には反映されません。

A. レベル 3（`/gamemode`、`/kick` は使えるが、`/stop` は使えない）
B. レベル 4（イメージの既定と思われる値で、`/stop` を含むすべてのコマンドを使える）
C. レベル 2（`/gamemode` は使えるが、`/kick` は使えない）
D. Not yet defined
X. Other (please specify)

[Answer]: A

A. 起動を中止して通知する（ホワイトリストの形式不正と同じ扱い）
B. 警告を通知して、そのまま起動する
C. 検査しない
D. Not yet defined
X. Other (please specify)

## Q3. [運用] オペレーターの秘匿パラメータが未登録のときは、どうしますか？

C. 起動を中止する（パラメータを必須にする）
D. Not yet defined
X. Other (please specify)
